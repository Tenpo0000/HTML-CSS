FUNDAMENTOS DE HTML


Tags e Estrutura: HTML utiliza tags (<conteúdo>) para marcar elementos. A estrutura básica é <html> <head>... Documento Básico: Um documento HTML5 começa com !DOCTYPE html para definir o tipo de arquivo. Cabeçalho e Corpo: head contém informações (título, meta-tags, links CSS), enquanto body contém o conteúdo visível (texto, imagens, etc.).


Header

O header, representado pela tag <head≷, contém informações importantes sobre a página, mas que não aparecem diretamente para o usuário. Nele ficam elementos como o título da página (<title≷), meta-tags (como a definição de caracteres e responsividade), links para arquivos CSS, ícones e outras configurações que ajudam o navegador a interpretar corretamente o site.


Body

o body, representado pela tag <body≷, é a parte onde fica todo o conteúdo visível da página. É dentro do body que colocamos textos, títulos, imagens, links, botões, listas, tabelas e qualquer outro elemento que o usuário verá e com o qual poderá interagir. Em resumo, enquanto o header cuida das configurações e informações internas do documento, o body é responsável por exibir o conteúdo propriamente dito.
